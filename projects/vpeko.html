VPE-Ko 한국어 영상 프롬프트 챗봇

영상 생성 모델은 대부분 영어 프롬프트를 전제로 만들어져, 한국어 사용자에게는 진입 장벽이 높습니다. 한국어로 대화만 하면 영상 생성용 영어 프롬프트를 완성해 주는 챗봇을, 학습 데이터부터 직접 만들었습니다.

기간

역할
팀 프로젝트 중 합성 데이터 구축, 한국어 LoRA 학습, 영상 생성 모델 스타일 LoRA 담당
환경
A100 80GB 1장

OVERVIEW대화로 프롬프트를 완성하는 흐름

공식 문서를 분석해 영상 품질을 좌우하는 핵심 요소 다섯 가지(주요 객체, 카메라 구도, 카메라 종류, 영상 속도, 조명)를 정하고, 챗봇이 이 요소를 한국어 대화로 하나씩 모으게 했습니다. 다 모이면 영어 프롬프트, 부정 프롬프트, 한국어 번역, 개선 제안 네 가지를 내놓고, 사용자의 구어체 피드백을 받아 다시 고칩니다.

이미지 자리: 챗봇 대화 화면

한국어로 주제를 말하고 질문에 답한 뒤 영어 프롬프트가 완성되는 대화 화면 캡처

projects/images/vpeko-chat.png

01합성 데이터 직접 구축

문제

핵심 요소를 차례로 묻고 모으는 한국어 대화 데이터는 공개된 것이 없었습니다.

방법

GPT 두 개에 역할을 나눠 서로 대화시켰습니다. 질문자는 챗봇 역할로 핵심 요소를 하나씩 묻고, 답변자는 사용자 역할로 답합니다. 답변자에게는 사투리, 반말, 문학체 등 약 30가지 말투를 무작위로 주고 주제도 자동으로 만들어, 실제 사용자처럼 다양한 입력이 나오게 했습니다.

결과

대화 5천여 건을 만들어 학습 쌍 24,769건으로 펼쳤습니다.

02LoRA 학습

설정

Qwen2.5-14B-Instruct에 LoRA(r=16, alpha=16, 모든 어텐션과 MLP 투영)를 bf16으로 붙여 trl SFTTrainer로 학습했습니다. 14B를 GPU 한 장에서 학습하도록 배치와 옵티마이저를 맞췄고, 추론 때는 LoRA 강도를 0.8 ~ 0.9로 낮춰 말투가 무너지지 않게 했습니다. 사전 단계로 Llama-3.1-8B와 Ministral-8B에 한국어 독해(KorQuAD) LoRA를 먼저 해 봤습니다.

연결

학습한 모델이 만든 영어 프롬프트를 CogVideoX에 바로 넘겨 영상까지 만드는 엔드투엔드 데모를 구성했습니다.

함께

영상 생성 모델 쪽에서는 CogVideoX-5B에 수묵화 스타일 LoRA를 학습했습니다. 수묵화 스캔 254장으로 영상 200편과 캡션을 구성했고, LoRA 강도를 0에서 1까지 바꿔 가며 비교 영상을 만들었습니다.

이미지 자리: 수묵화 스타일 LoRA 결과

같은 프롬프트로 LoRA 적용 전과 후에 생성한 영상의 프레임 비교

03평가

영상 생성 모델을 써 본 적 없는 참가자 10명이 직접 쓴 프롬프트(A)와 챗봇으로 만든 프롬프트(B)를 비교했습니다. 프롬프트는 G-Eval과 만족도로, 각 프롬프트로 만든 영상은 만족도로 평가했습니다.

이미지 자리: A-B 생성 영상 비교

"뜨겁게 타오르는 화산"처럼 같은 주제로 A 프롬프트와 B 프롬프트가 만든 영상 프레임을 나란히

projects/images/vpeko-ab.png

04후속 연구와 돌아보기

후속

팀은 이 시스템을 생성된 영상이 의도와 어긋났을 때 원인을 진단하는 KoPESV-SD로 확장해 저널에 게재했고, 그중 생성이 끝나기 전에 실패를 경고하는 파트를 맡았습니다. 50스텝 중 11스텝까지만 생성한 중간 상태로 다섯 요소별 실패 가능성을 판정하는 방식입니다.

다시 한다면

대화 종료 조건 때문에 최종 프롬프트 예시가 학습 데이터에 빠진 점, 일부 데이터에서 챗봇과 사용자 역할이 뒤바뀐 점, 대화를 단일 턴으로 쪼개면서 앞 문맥이 사라진 점을 데이터 설계의 개선점으로 정리했습니다. 이후 학습에서는 학습 전에 데이터 통계와 형식을 먼저 확인하는 것을 습관으로 삼았습니다.
