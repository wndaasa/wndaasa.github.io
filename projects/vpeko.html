01챗봇 설계

1-1핵심 요소 다섯 가지와 대화 흐름

CogVideoX의 공식 예제 프롬프트를 분석하여 영상 품질을 좌우하는 핵심 요소로 주요 객체, 카메라 구도, 카메라 종류, 영상 속도, 조명 다섯 가지를 정하고, 챗봇이 이 요소를 한국어 대화로 하나씩 모으게 했습니다. 다 모이면 영어 프롬프트, 부정 프롬프트, 한국어 번역, 개선 제안 네 가지를 내놓고, 사용자의 구어체 피드백을 받아 다시 고칩니다.

02합성 데이터 구축

2-1GPT 두 개의 역할 대화

핵심 요소를 차례로 묻고 모으는 한국어 대화 데이터는 공개된 것이 없어, gpt-4o-mini 두 개에 역할을 나눠 서로 대화시켰습니다. 질문자는 챗봇 역할로 핵심 요소를 하나씩 묻고, 답변자는 사용자 역할로 답합니다. 답변자에게는 사투리, 반말, 문학체 등 약 30가지 말투를 무작위로 주고 주제도 자동으로 만들어, 실제 사용자처럼 다양한 입력이 나오게 했습니다.

대화 5,127건을 만들고, 대화를 턴 단위의 질문과 답변으로 나눠 학습 쌍 24,769건을 구성했습니다.

03LoRA 학습

3-1한국어 LoRA 설정

Qwen2의 모든 어텐션과 MLP 투영에 LoRA(r=16, alpha=16)를 붙여 trl SFTTrainer로 1 epoch 학습했습니다. 양자화 없이 bf16 그대로 GPU 한 장에서 학습했고, 옵티마이저는 paged AdamW, 스케줄은 cosine을 썼습니다.

학습한 모델이 만든 영어 프롬프트를 CogVideoX에 바로 넘겨 영상까지 만드는 Flask 데모로 연결했습니다.

3-2수묵화 스타일 LoRA

영상 생성 모델 쪽에서는 CogVideoX-5B에 수묵화 스타일 LoRA를 학습했습니다. 수묵화 스캔 254장으로 영상 200편을 만들고, 캡션은 CogVLM2 캡션 모델로 붙였습니다.

720×1280, 49프레임 영상을 A100 한 장에서 학습하기 위해 gradient checkpointing, VAE tiling과 slicing, 단일 프로세스 DeepSpeed ZeRO-3를 함께 썼습니다. 학습 후에는 LoRA 강도를 0에서 1까지 바꾼 비교 영상으로 화풍이 입혀지는 정도를 확인했습니다.

04트러블슈팅

4-1LoRA 강도를 높이면 학습한 말투로만 답함

문제

LoRA 강도를 높게 두면 학습한 말투로만 답했습니다.

해결

추론 때 LoRA 강도를 실사용하며 0.8 ~ 0.9로 조절했습니다.

4-2학습 데이터 설계 결함 3건

문제

대화 종료 조건 때문에 최종 프롬프트 예시가 학습 데이터에 빠졌고, 일부 데이터에서 챗봇과 사용자 역할이 뒤바뀌었으며, 대화를 단일 턴으로 쪼개면서 앞 문맥이 사라졌습니다.

해결

이후 학습에서는 학습 전에 데이터 통계와 형식을 먼저 확인하는 것을 습관으로 삼았습니다.

4-3한국어 답변에 중국어 토큰이 섞임

문제

Qwen2가 한국어로 답하는 중간에 중국어 토큰을 섞어 냈습니다.

해결

추론 결과의 유니코드 범위를 검사해 한자가 섞이면 다시 생성하도록 했습니다.
