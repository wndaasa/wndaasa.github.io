Elasticsearch 기반 현행 검색 시스템을 EXAONE, bge-m3, pgvector, MCP 구성으로 대체했습니다.

01하이브리드 검색 설계

설계

LLM 검색어 확장, MCP 키워드 검색과 pgvector 의미 검색, 가중 RRF 결합, LLM 목록형 재순위 순으로 검색합니다. 앞단의 질의 의도 라우터가 검색이 필요 없는 질의는 바로 답합니다.

라우터

검색, 상세, API, 외부지식, 잡담 5분류 프롬프트를 설계해 단일 질의 153/156, 멀티턴 29/30 정확도, 평균 0.06초.

무결과

의미 없는 입력을 거르는 임계값은 무의미 질의 60개와 정상 질의 199개로 오판 수를 재서 0.64로 정했습니다.

02벡터 구성 실험과 Elasticsearch 대체

실험

13만 건 전체를 임베딩한 뒤 필드를 하나로 합친 벡터, 필드별 가중합, 유사도 가중합을 비교하고, 가중치는 0.1 간격 1,001개 조합을 탐색했습니다.

결정

튜닝셋과 시험셋을 분리해 과적합을 막고 제목과 설명을 0.5:0.5로 합친 벡터를 택했습니다. MRR@20이 튜닝셋 0.830 → 0.850, 시험셋 0.736 → 0.754. 청킹은 토큰 분포와 순위 변화를 분석한 결과 이득이 없어 적용하지 않았습니다.

대체 범위

운영팀 회신을 바탕으로 Elasticsearch가 쓰이던 경로 다섯 곳과 색인 배치에서 만료 상품이 빠지던 문제를 정리해 대체 범위를 정했습니다.

03검색 API 서버

구현

인터페이스 정의서를 기준으로 FastAPI 서버를 새로 작성했습니다. 검색, AI 요약 스트리밍(SSE), 멀티턴 챗봇, 대화 이력, 관련 데이터셋 조회를 제공합니다.

검증

기존 서버와 같은 199문항을 돌려 hit@1 149 대 149로 동등함을 확인한 뒤 Docker 이미지로 운영 환경에 배포했습니다.

관측

요청마다 trace_id를 붙여 응답 시간, 에이전트 경로, LLM 토큰, MCP와 임베딩 호출 결과를 JSON 한 줄로 남기고, 이 로그에서 평가 지표를 바로 뽑게 했습니다.

04검색 품질 평가

hit@1, hit@3, F1@3, nDCG@3, 처리 시간을 기준으로 평가 체계와 채점 스크립트를 만들고, 현행 검색 시스템과 같은 100문항으로 비교했습니다.

평가셋 재설계. 감리에서 평가셋의 독립성을 지적받아 데이터 난이도 기준으로 99문항 시험 평가셋을 새로 만들고 사후 블라인드 판정 방식으로 바꿨습니다.

05GPU 추론 서버

구성

k3s 단일 노드로 vLLM을 띄웠습니다. EXAONE-4.0-32B-AWQ는 TP=2, bge-m3는 레플리카 2개로 GPU를 지정해 공존시켰습니다.

메모리

GPU 메모리는 사용률 비율 대신 모델별로 필요한 KV 캐시 토큰 수로 계산해 배분했습니다.

출력 제어

개발용 Qwen 모델이 한자와 가나를 섞어 쓰는 문제를 logits processor로 막았습니다. 어휘 24.8만 개 중 5.9만 토큰을 차단했고 한글 토큰 영향은 0이었습니다.

투기 디코딩과 vLLM 패치는 32B 서빙 최적화 페이지에 정리했습니다.

06보안과 부하

보안

OWASP LLM Top 10 (2026) 기준으로 입력과 외부 자료 정제, 프롬프트 안 자료 경계 태그, 도구 인자 검증, API 키 인증, 개인정보 로그 마스킹을 반영했습니다.

부하

vLLM 프리픽스 캐시 효과는 무작위 프롬프트로 밀어내 제거하고, 같은 GPU를 쓰는 다른 작업에 오염된 표본은 분리한 뒤 부트스트랩 신뢰구간으로 산출했습니다.

간헐적 500 오류. httpx와 vLLM의 keep-alive가 둘 다 5초라 연결 재사용 시점이 겹치는 경쟁 조건이었습니다. 4.996 ~ 4.999초 구간에서 재현해 원인을 확정하고 클라이언트 설정으로 해결했습니다.

07MCP 연동과 감리 대응

MCP

외부 기관의 MCP 서버, 도구 45개를 챗봇에 MCP 클라이언트로 연동하는 시연을 구현했습니다. 질의 판정 25/25.

감리

인터페이스 정의서, 적합성 평가 계획서와 결과서, 모델 라우팅 기준서를 작성했습니다. 양자화 근거, 컨테이너 운영, 평가셋 독립성, 모델 선정 근거 등 감리 지적 13건은 실측과 코드로 대조해 대응했습니다.

진행 중
